# EVLuminio · Cotizador Web

Aplicación web minimalista para cotizar de forma interactiva:

- Ventanas
- Puertas
- Canceles de baño
- Barandales

## Funcionalidades

- Captura de medidas (ancho y alto).
- Selección de producto, color de aluminio, cristal, instalación y ubicación.
- Cálculo estimado dinámico con desglose.
- Resumen visual premium para clientes de Guadalajara y Zapopan.
- Botón para enviar el pedido por WhatsApp con el detalle precargado.

## Uso local

Abre `index.html` en tu navegador o levanta un servidor estático:

```bash
python -m http.server 4173
```

Después visita `http://127.0.0.1:4173`.
